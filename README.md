# Zephyr Android

B4A/Android project Zephyr Android (`ZephTst.b4a`, application label Zeph Test, package `canalrun.apps.zephtest`). Bluetooth serial test app for Zephyr device packets (heart rate, distance, speed, strides).

## Contents

- `ZephTst.b4a` — B4A project (version 3.5)
- `MyUtils.bas`, `HdgLabel.bas`, `GrdLabel.bas` — modules
- `Files/tst.bal` — layout
- `Objects/AndroidManifest.xml`, `Objects/res/drawable/icon.png`

The project file also names module `ChatActivity`, which was not present in the source archive.
